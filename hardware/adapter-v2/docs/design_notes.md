# 设计说明与接线依据

## 接口 A / B 的固定差异

名称 A/B 指两类接口线序，不表示自动识别的屏幕型号，也不表示屏幕座的插入面。五款屏幕具体属于哪个接口，仍应按屏幕的实际 FPC 定义核对。

| 引脚 | J2：图 2 线序 A | J7：图 3 线序 B |
|---|---|---|
| 1 | SPI SDA | SPI SDA |
| 2 | SPI SCL | SPI SCL |
| 3 | RESET | CS |
| 4 | CS | RESET |
| 5 | GND | GND |
| 6 | **NC，原理图明确不连接** | GND |
| 7 | DE | DE |
| 8 | VSYNC | VSYNC |
| 9 | HSYNC | HSYNC |
| 10 | **NC，原理图明确不连接** | 3.3V |
| 11 | PCLK | PCLK |
| 12 | GND | GND |
| 13…20 | B7…B0 | B7…B0 |
| 21…28 | G7…G0 | G7…G0 |
| 29…36 | R7…R0 | R7…R0 |
| 37 | 3.3V，待屏幕规格确认 | 3.3V，待屏幕规格确认 |
| 38 | GND | GND |
| 39 | LEDA | LEDA |
| 40 | LEDK | LEDK |

图 2 符号内部的引脚文字与外侧网络标签不一致。设计依据是外部网络标签和明确的引脚编号；没有用内部错位文字反推线序。两个屏幕座没有换线焊桥。开发板信号仅引出了 RGB565：LCD R0…R2、G0…G1、B0…B2 固定接地，R3…R7/G2…G7/B3…B7 传递有效数据。必须在具体屏幕初始化中选择支持这种高位映射的 RGB 接收模式；这不是 RGB888 全色深接口。

## 33Ω 排阻决定

采用四路独立排阻，每路对应引脚对 **1-8、2-7、3-6、4-5**。

| 排阻 | 四路信号 |
|---|---|
| RN1 | R3、R4、R5、R6 |
| RN2 | R7、G2、G3、G4 |
| RN3 | G5、G6、G7、B3 |
| RN4 | B4、B5、B6、B7 |
| RN5 | PCLK、HSYNC、VSYNC、DE |

33Ω 是初始装配值，用于减小振铃和边沿过冲，实际可换同封装的 22Ω/0Ω。有效源端阻尼最好靠近 H743 的输出管脚；本转接板受开发板位置限制只能放在输入座 J1 附近。因此不能声称这五组电阻已经保证任意长度 FFC 的信号完整性。后续布线应短接、保持地参考连续，控制两个屏幕座形成的开路支路长度，并实测像素时钟边沿和数据建立保持时间。若开发板本身已串电阻，应核对总阻值。

## PY32 与 H743 的控制关系

| PY32 引脚 | 用途 |
|---|---|
| PA0，封装 11 | 软 SPI 时钟，经 R8 到 LCD_SCL |
| PA1，封装 12 | 软 SPI 数据，经 R9 到 LCD_SDA |
| PA2，封装 14 | 片选，经 R10 到 LCD_CS |
| PA3，封装 15 | 屏复位，经 R11 到 LCD_RST |
| PA6，封装 16 | READY，初始化完成后置高 |
| PA13，封装 6 | SWDIO |
| PA14，封装 7 | SWCLK |
| PF2，封装 8 | NRST |
| PA9，封装 5 | 预留 TX_LOG，引到下载排针，不要求使用 |
| VCC 4 / VSS 13 | 3.3V / GND |

SCK/SDA/CS/RESET 均为固定连接；R8…R11 为 100Ω 串阻，不承担型号选择功能。程序按具体屏幕手动刷写：8 位/9 位传输格式、SPI mode、复位时序、寄存器表、分辨率和 RGB 时序都取自该屏的资料。本轮未提供或虚构初始化表。

H743 上电保持 PB5 背光输出低，PG3 配成输入，等待 READY。PY32 上电保持 PA6 低，完成当前屏幕初始化及必要延时后拉高 PA6。U4 为 AND 门，背光实际使能 = PB5 与 PA6。H743 的 RESET 经 R16=0Ω 接 PY32 NRST；独立下载调试若被开发板复位影响，可不装该 0Ω 电阻。

J6 下载口顺序：1=3.3V 参考，2=GND，3=SWDIO，4=SWCLK，5=NRST，6=TX_LOG。3.3V 是参考电压，不作为未经核对的下载器反向供电入口。

## 触摸复用

H743 原触摸 SPI 引脚改作：PH6=SCL、PI3=SDA、PH7=INT、PI8=RST。SCL/SDA 按软件 I²C 使用，不能直接沿用原电阻触摸 SPI 驱动。PG3 原 T_MISO 用于 READY。

| 触摸座 | 1…6 脚 |
|---|---|
| J3 / J5（图 4 左/右） | 3.3V、GND、SCL、SDA、INT、RST |
| J4（图 4 中） | GND、3.3V、INT、SCL、SDA、RST |

SCL、SDA 各一只 4.7kΩ 上拉；触摸模块已有上拉时复核并联总值。三个座并联，一次只插一个触摸尾排。触摸控制器型号和 I²C 地址未从截图推断。

## 电源、背光和热设计

开发板 J1 的 1/2 脚为 5V，本板用 AP2112K-3.3TRG1 产生逻辑 3.3V。LDO 热损耗约为 1.7V × 逻辑总电流；600mA 是芯片电流规格，不是当前 PCB 铜面积下的热保证。当前只做布局，布线时应核对实际显示逻辑、触摸和 PY32 总电流，必要时更换供电方案。

SY7200ABC 的引脚为 1=LX、2=GND、3=FB、4=EN/PWM、5=OVP、6=IN。R4 保持 5.1Ω/1%，标称背光总电流 **0.2/5.1 ≈ 39.2mA**，来自原项目参考，不代表五款屏幕都应使用这一电流。LEDK 连接 FB/采样电阻，不能直接接地。背光器件的封装和相对摆放参考 `T113_MIPI_Adapter` 的最终版本：L1 为 C5832360 / FTC252010S4R7MBCA 的 2.5×2.0mm CAD 封装，C9/C10/C11 使用 0805，R4 使用 0603。

升压输出电容 C11 采用 10µF/50V、0805，考虑开路过压可接近 33V，实际有效电容需考虑直流偏压。电感 4.7µH 采用 T113 工程已确认的 2.5×2.0mm CAD 封装，具体料号仍需满足实际饱和电流、温升和 DCR。该升压方案要求背光串压高于 5V；五款屏幕的 LED 串并联形式、目标电流及功率未给出，仍需逐款核对。

## 封装依据与机械边界

J1/J2/J7 暂选 **Omron XF2M-4015-1A 双面触点 40Pin/0.5mm**；因此分成两座后仍可使用相同机械封装，但两座电气线序固定不同。J3/J4/J5 暂选同系列 XF2M-0615-1A，6Pin/0.5mm。不是把上接和下接任意座子当作相同焊盘。

官方系列资料规定 FPC/FFC 厚度 0.3±0.05mm。40Pin 使用 KiCad 自带 XF2M 封装，6Pin 根据同系列尺寸表由 40Pin 封装缩短 17mm：触点跨度 2.5mm、0.5mm pitch，安装焊盘中心 x=±2.9mm；每个接点焊盘 0.25×1.1mm，安装焊盘 1.7×1.5mm。40Pin 接点跨度为 19.5mm，安装焊盘中心 x=±11.4mm。安装金属脚统一标成 MP 并接地。

实际尾排的厚度、补强、裸露金手指长度、1 脚方向仍需确认。开发板至本板要验证 **J1.1 确实对应开发板引脚 1**，不能根据“同面线/异面线”称呼猜测。屏幕座本身双面接触也不自动解决左右反序问题。

板框 78×75mm 是初始布局尺寸，未添加未经指定的安装孔。4 层规划为信号/GND/电源/信号，尚未确定制造商叠层、阻抗、板厚要求。原理图不声称五款屏幕已完成点亮验证。

KiCad 渲染中部分连接器没有官方 3D 模型，焊盘和封装边界完整，3D 图仅辅助查看布局，不能用于校核插拔空间。
